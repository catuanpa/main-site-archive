# main-site-archive

## 项目简介

本仓库用于归档和发布多个独立的 HTML 页面。这些页面可能来源于不同的时间、不同的项目或不同的用途，统一存放在此以便于访问、分享和长期维护。

该仓库不针对任何特定域名或网站，仅作为静态 HTML 资源的集合地。每个页面均保持其原始结构和内容，不做额外修改或重定向。

## 目录说明

```
main-site-archive/
├── README.md          # 本文件
├── index.html         # 仓库首页 / 导航页（可选）
├── page-001.html      # 归档页面示例
├── page-002.html
├── assets/            # 页面公共资源（如 CSS、JS、图片）
│   ├── style.css
│   └── images/
└── archive/           # 按时间或主题组织的子目录（可选）
    └── 2024/
        └── example.html
```

- 根目录下的 `.html` 文件为独立归档页面。
- `assets/` 存放页面可能用到的共用资源文件。
- `archive/` 用于按日期、主题或来源整理页面，保持根目录整洁。

## 页面归档说明

每个归档页面通常代表一个独立的内容单元。页面的来源、时间、用途等信息可在文件头部注释中标注（如适用）。归档时遵循以下原则：

- 保持页面原始内容和结构，仅做必要的兼容性调整。
- 避免引入外部依赖（如第三方 CDN），以确保页面可离线或长期可用。
- 文件名建议使用有意义的英文命名，避免特殊字符。

## 维护说明

- 本仓库由维护者不定期更新，新增页面或调整目录结构。
- 欢迎提交 Issue 或 Pull Request 建议新增归档内容，但需确保内容合规且不涉及侵权。
- 不建议直接修改已有归档页面的核心内容，如需更新请以新版本形式添加。
- 仓库历史提交记录保留页面变更日志，方便追溯。
